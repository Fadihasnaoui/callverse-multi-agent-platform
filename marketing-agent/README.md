# Marketing Agent

This folder contains the Marketing Agent implementation used by the Callverse platform.

## Backend

The backend source covers campaign strategy, content generation, scheduling, publishing, metrics, audience leads, business settings, competitor monitoring, memory, audit, media assets and reporting.

## Frontend

The dashboard source includes the marketing overview, content workspace, publishing calendar, catalogue, leads, audit, AI statistics, costs and settings views.

The Marketing Agent shares the Callverse platform services and user interface system while remaining available as its own workspace.
